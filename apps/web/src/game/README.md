# Игра (шахматы онлайн)

Отдельный модуль: **ни один существующий файл фронта не изменён**.

- Запуск: `pnpm dev` -> http://localhost:5173/game.html
- Логин общий с основным сайтом (токен лежит в localStorage под ключом `token`).
- Бэк нужен на `VITE_API_URL` (по умолчанию http://127.0.0.1:3000), CORS_ORIGINS должен включать адрес фронта.

## Файлы
- `GameApp.tsx` - вход, лобби, экран партии (доска, часы, ничья, сдача, превращение пешки)
- `gameApi.ts` - клиент для `/games/*` по `docs/API.md`
- `chess.ts` - генератор ходов только для подсказок; правила проверяет сервер

## Для продакшн-сборки
`game.html` собирается только если добавить его в `vite.config.ts` (это правка файла фронтендера):

```ts
build: { rollupOptions: { input: { main: 'index.html', game: 'game.html' } } }
```

Дальше можно подключить `GameApp` прямо в `App.tsx` вместо заглушки лендинга.
